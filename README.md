# Project Topic: An Interactive-report-card system

## Project Overview
Designing an automated and interactive report card system for a Secondary School. In this project, you (The principal) would be able to:

(a) View individual student reports

(b) Analyze performance across subjects

(c) See rankings

(d) Use dynamic charts to visualize performance.

## Project Brief
This is an excel workbook that includes a report card template sheet (well designed with the school name, logo and motto), a data entry sheet and a dynamic report summary sheet that auto-fills based on selected student.

## Data source
Data entry sheet on excel that contains student information, scores, positions, remarks.

## Skills Applied
- Data Validation (for student name drop down)
- Charting (for Visualizing scores)
- Sorting (for determining positions)
- Conditional formatting (for color-coded performance)
- Sheet design (presentation and structure)
