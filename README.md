# Project Topic: An Interactive-report-card system

## Project Overview
Designing an automated and interactive report card system for a Secondary School. In this project, you (The principal) would be able to:

(a) View individual student reports

(b) Analyze performance across subjects

(c) See rankings

(d) Use dynamic charts to visualize performance.

## Project Brief
This is an excel workbook that includes a report card template sheet (well designed with the school name, logo and motto), a data entry sheet and a dynamic report summary sheet that auto-fills based on selected student. Two dynamic charts that shows total score per student and the selected student's subject score which updates with name selection.

## Data source
Data entry sheet on excel that contains student information, scores, positions, remarks.

## Tools used
- Microsoft Excel [click here](https://www.microsoft.com)

## Skills Applied
- Data Validation (for student name drop down)
- Charting (for Visualizing scores)
- Sorting (for determining positions)
- Conditional formatting (for color-coded performance)
- Sheet design (presentation and structure)

## Data Preparation
In the different phases of the preparation we designed the report card template to include the school name, school motto, logo. We gave it a clean professional layout with student details, subject tables and totals. A visual formatting was included to highlight performance level of each student.

## Data Entry
In this phase, each column in the data entry sheet is to include Student name, Gender, Age, Class, Subjects of choice, Test scores, Total scores, Remarks, Position in class. With their Remark scale showing as follow
- 80 - 100: Excellent (A)
- 60 - 79: Very good (B)
- 50 - 59: Good (C)
- 40 - 49: Average (D)
- 30 - 39: Poor (E)
- 0 - 29: Very poor (F)

## Data Report summary
In this phase several excel functions were employed for use; XLOOKUP, IF STATEMENT, RANK.EQ, including the use of conditional formatting, filters to add a dropdown menu in selecting students and when selected, the Student Information, Subject-wise scores, total score, remarks, class position is on display with the sheet automatically updating when a different student is selected.

## Data Visualization
A bar chart displaying the total scores per student and also, a column chart showing subject performance which updates automatically with each name selection.
